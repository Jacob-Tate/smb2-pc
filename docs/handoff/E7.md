Status: IN PROGRESS (see bottom for what was verified).

## What exists
- `src/overlay/tab_online.cpp`: the tab (disconnected / connecting / connected / in room / session views), the online action
  functions (`online_connect/host/join/pick_port/start/leave_room/disconnect/leave_session`), `online_tick()` and the test script.
- `src/overlay/overlay_ui.{h,cpp}`: new rows `text_row` (keyboard text field inside a row), `stepper_row`, `action_row`; `online_locked()`.
- `src/platform/pc_settings.c` + `include/pc_settings.h`: `np_server`, `np_name` in settings.dat (`pcs_set_netplay`).
- `src/overlay/overlay.cpp`: `overlay_poll_tick` calls `ovl::online_tick()` (lobby events -> toasts even when the overlay is closed),
  title screen hint "F1 / Back+Start: Online" (main_mode 0 / sub_mode 8 = the "PRESS START" screen, found empirically, not in a session, menu closed).
- netplay API additions (additive, small): `netplay_session_leave()`, `NetplayRoomInfo.in_game`, `netplay_lobby_room()` also answers while
  the session runs (delay = session delay), `--overlay-test-online-script` added to the relaunch strip list.
