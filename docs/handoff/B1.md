# B1 handoff: DiscReader

Status: DONE (branch task/B1).

## What exists
- `src/assets/disc_reader.{c,h}`: opaque `DiscReader` (format string, size, read fn, close fn).
  API: `disc_reader_open(path, err, errsz)`, `disc_reader_size`, `disc_reader_read(r, u64 off, u32 len, dst)`,
  `disc_reader_close`, `disc_reader_format`. `read` is false when any byte lies outside `[0, size)`.
- Backend by magic in `disc_reader_open`: `RVZ\x01` -> error "... is an RVZ image; RVZ is not supported yet
  (convert it to ISO)"; everything else -> plain image (`_fseeki64` / `fseeko`, format "iso").
- `iso.c`: `ISOArchive.file` replaced by `DiscReader* reader`; `iso_open`, `iso_read_raw`, `iso_extract_file`,
  `iso_file_read_at` use it. Dead `is_rvz/rvz_data/rvz_size` and `iso_read_rvz_header` removed.
  The extracted-folder backend (`is_dir`, `cur_file`) is unchanged.
- `gamedata.c`: `check_image` uses the reader (`file_size64` removed). Extraction reads go through
  `iso_file_read_at` / `iso_read_raw` -> reader.
