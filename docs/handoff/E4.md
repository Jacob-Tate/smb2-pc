# E4: Local determinism tests

Status: IN PROGRESS (x64 only, D-9).

## Tool
`tools/determinism/determinism.sh` (Git Bash; the exe is a Windows exe, no Windows Python exists, so no WSL/interop dependency).
Records `race` (Monkey Race 2 pads, 4500 polls) and `mg` (Main Game stage, 7500 polls) with the same input scripts as
`tools/smoke/record_replay.sh` (unless `--rec-dir` already holds them), then replays each N times over a matrix, N jobs in parallel,
each with its own cwd + throwaway `--save-dir`, `--audio-null`, Steam Controller ignored via SDL env. Every replay checksum log is
compared byte-for-byte with the recording's own log.

```
tools/determinism/determinism.sh --out C:/tmp/e4 --jobs 4                 # acceptance: 2 renderers x fps 60/144 x 3 runs x 2 scenarios
tools/determinism/determinism.sh --out C:/tmp/e4 --scenarios race --t2    # + uncapped, no-vsync, msaa 0/8, 1280x720
tools/determinism/determinism.sh --variants "a=--renderer gl --fps 60;b=--renderer d3d12 --fps 90" --runs 2
```
Exit 0 only if all identical. Reuse recordings: `--rec-dir`.
