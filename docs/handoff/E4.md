# E4: Local determinism tests

Status: DONE for T1-T5, acceptance PASS; T7 static only; T8/T9 not run (see below). x64 only (D-9).

## Tool
`tools/determinism/determinism.sh` (Git Bash; the exe is a Windows exe, no Windows Python exists, so no WSL/interop dependency).
Records `race` (Monkey Race 2 pads, 4500 polls) and `mg` (Main Game stage, 7500 polls) with the same input scripts as
`tools/smoke/record_replay.sh` (unless `--rec-dir` already holds them), then replays each N times over a matrix, N jobs in parallel,
each with its own cwd + throwaway `--save-dir`, `--audio-null`, Steam Controller ignored via SDL env. Every replay checksum log is
compared byte-for-byte with the recording's own log.

```
tools/determinism/determinism.sh --out C:/tmp/e4 --jobs 4                 # acceptance: 2 renderers x fps 60/144 x 3 runs x 2 scenarios
tools/determinism/determinism.sh --out C:/tmp/e4 --scenarios race --t2    # + uncapped, no-vsync, msaa 0/8, 1280x720
tools/determinism/determinism.sh --variants "a=--renderer gl --fps 60;b=--renderer d3d12 --fps 90" --runs 2
```
Exit 0 only if all identical. Reuse recordings: `--rec-dir`.

Extra options: `--real-audio` (no `--audio-null` on replays, T3), `--seed-settings FILE` (copies FILE to `<save-dir>/settings.dat`, T4).
Test hook added (shim, test-only): env `SMB2_TEST_FILL=<hex byte>` pre-fills the 24 MiB arena (`gc_mem.c`) and ARAM (`ar_shim.c`) (T5).

## D1 note: attract/title pixel noise
Two det-session runs (`--det-session --exit-frame 811 --dump-from 690`, no input), compared with a pixel diff:
- GL fps default: 102 of 121 frames in 690-810 differ; GL `--fps 60` (no HFR): still differ; D3D12 `--fps 60`: differ too.
- Magnitude: 2-180 pixels of 1.44 M, max 1/255 on GL, up to 13/255 on D3D12; positions scatter over foliage/huts (different cells each frame, not a fixed spot).
- The sim checksum at polls 720 and 780 is identical in all 24 replays, so any sim difference is below what the hash covers.
- No wall-clock/random call exists in `src/render` or the gx shims (only perf counters for profiling). Not proven render-only: persistence across both renderers points at something upstream of the backends (a time-driven value the hash does not cover, or GPU sampling noise from identical inputs). Not fixed here. Suggest as follow-up: dump per-poll checksum (or ball/camera floats) around poll 700-800 in two runs to see if a sim value differs.
- Does NOT affect the matrix (the hash is sim-only) or gameplay later (race/mg runs match).

## Gotchas
- A rebuild during a running matrix replaces the exe under the runs: wait for the matrix to end first.
- Replays take ~75-125 s each at real time; 24 runs at 4 jobs ~12 min. Parallel runs do not disturb determinism.
- Use Windows-style paths (`C:/...`) for `--out`/`--rec-dir`; scripts run from Git Bash, backgrounding from the Bash tool needs `nohup ... &`.
