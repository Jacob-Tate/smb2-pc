## Conventions

- ENet/UDP, default port 7855, `SMB_NET_PROTOCOL_VERSION 1`. Channel 0 = control, channel 1 = input
  (INPUT, FRAME). Both reliable+ordered, **but channel 0 and 1 are not ordered against each other**.
- Little-endian, no padding. Packet = u8 type + fields. `str` = u8 length + bytes (no NUL).
  Helpers `smbw_*` / `smbr_*` (bounds-checked). `SmbNetPad` (9 bytes) and `SmbNetSessionConfig` (58 bytes)
  are `#pragma pack(1)` with static asserts; the writers serialize field by field anyway.
- **Time base is the poll** (one `input_poll_gc_pads` call from `video_finish_frame`, see E1), not the tick.
  Poll numbers start at 0 for each GAME_START.
- Lockstep with delay D (from the session config): to finish poll P the client sends INPUT for poll P+D, then
  blocks for FRAME P. After GAME_START it first sends neutral INPUT for polls 0..D-1. The server only emits
  FRAME P once every human port supplied poll P.
- `gameSeq` (u8, 1..255 per game in a room) is in GAME_START, INPUT and FRAME. Clients drop FRAMEs whose seq
  isn't the current game's (stale frames can arrive after the next GAME_START); the server ignores stale INPUT.
- FRAME `humanMask` is authoritative per poll: a port not in the mask is neutral (E9 decides whether the game
  sees `err = 0` neutral or `err = -1`; the wire just omits the pad). PLAYER_DROPPED is informational (toast).
- Checksum: client sends CHECKSUM when `poll % 60 == 0 && poll > 0`, with the poll number it just completed
  (E3's curated hash). The server compares once every current human has reported that poll.
- Must-match config: build id, disc manifest hash (u32, `fst_crc32`), locale (u8) come from HELLO; the room
  stores the creator's. JOIN_ROOM is refused with `SMB_ERR_CONFIG_MISMATCH` (message names the field) if they
  differ; START_GAME's config must match them too. Host-chosen: inputDelay (<= 30) and flags (known bits only,
  `SMB_CFG_FLAG_ALLOW_CROSS_ARCH`). Server-chosen: epoch (random u64 per game). Protocol version is checked at HELLO.
- Rooms persist until empty (members leave/disconnect). Desync or host END_GAME: `GAME_ENDED` + lobby
  `ROOM_STATE`, same members and ports; the host can START_GAME again. No late join, no rejoin, no restart.
- Host leaves/disconnects: host role passes to the first remaining member (also mid-game).
- Server never validates pad contents (opaque 9 bytes).

## Message table

Client -> server

| id | name | fields | when |
|---|---|---|---|
| 1 | HELLO | u16 protocol, str name (<=24), str buildId (<=40), u32 discHash, u8 locale | right after connect; before anything else |
| 2 | CREATE_ROOM | - | lobby; leaves the current room; sender becomes host on P1 |
| 3 | JOIN_ROOM | char[4] code (case-insensitive) | lobby; needs a free port, matching config, room not in game |
| 4 | LEAVE_ROOM | - | any time; mid-game = a drop |
| 5 | START_GAME | SessionConfig (58 B) | host only, lobby; build/disc/locale must match room; epoch ignored |
| 6 | INPUT | u32 poll, u8 gameSeq, u8 pad[9] per owned human port (port order) | in game, once per poll (poll+D) |
| 7 | CHECKSUM | u32 poll, u32 hash | in game, every 60 polls |
| 8 | CHOOSE | u8 port (0-3 or 0xFF keep) | lobby; move to a free port, else ERR_TAKEN |
| 9 | PERF | u32 poll, u16 polls, u16 slowPolls, u16 stalls, u16 worstMs | every 60 polls and after a slow poll; deltas since the last PERF |
| 10 | END_GAME | - | host only, in game; ends it for all (reason HOST) |

Server -> client

| id | name | fields | when |
|---|---|---|---|
| 64 | WELCOME | u8 clientId | reply to a valid HELLO |
| 65 | ERROR | u8 code, str message | any rejected request (1 bad msg, 2 version, 3 no room, 4 full, 5 in game, 6 not host, 7 bad settings, 8 taken, 9 config mismatch) |
| 66 | ROOM_STATE | char[4] code, u8 hostId, u8 count, count x (u8 id, str name, u16 pingMs), 4 x u8 owner (0xFF none), u8 phase (0 lobby, 1 in game) | any membership/port/phase change; lobby ping refresh when a ping moved >= 5 ms |
| 67 | GAME_START | SessionConfig (epoch set), 4 x u8 portOwner, u8 gameSeq | START_GAME accepted; all members |
| 68 | FRAME | u32 poll, u8 gameSeq, u8 humanMask, u8 flags (0x01 mask changed), u8 pad[9] per mask bit | every poll, in order, once all human inputs are in |
| 69 | DESYNC | u32 poll | checksum mismatch; followed by GAME_ENDED(desync) and lobby ROOM_STATE |
| 70 | GAME_ENDED | u8 reason (1 last human left, 2 desync, 3 host), u8 clientId (or 0xFF) | game over; room is in the lobby phase |
| 71 | PLAYER_DROPPED | u8 clientId, u8 ports (bit per port), u32 poll | a player left mid-game; those ports are neutral from `poll` |
| 72 | WAITING | u8 missingPorts, u16 waitedMs | every 0.5 s while a poll is held up |
| 73 | NET_STATS | u8 count, count x (u8 id, u16 ping, u16 jitter, u8 lossPct, u16 late, u16 slowPolls, u16 stalls, u16 worstMs) | once a second in game; late = last to arrive beyond usual by >= 20 ms (server side) |

## Notes for E6/E8/E9

- Partyboard's PERF/NET_STATS were only in its protocol 8 (not in the header I was given); the layouts above are
  new here. The late detection is the server's (`noteLateness`).
- HELLO carries the must-match fields so JOIN can be refused before any game; the client should still compare the
  GAME_START config against its own (`smb_config_mismatch`) as a safety net.
- Server tests: `smb2-server-test` covers 2 and 3 players, lobby/ports, mismatch rejections, 200-poll exchange, checksum
  match/mismatch, restart in the same room, drop (disconnect and LEAVE), WAITING, NET_STATS, room full, room closing.
