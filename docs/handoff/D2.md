# D2: Dear ImGui Direct3D 12 backend (in progress)

## What exists
- `src/overlay/overlay_d3d12.{h,cpp}`: bridge owning the ImGui DX12 backend and a private 8-slot shader-visible SRV heap
  (font atlas). `overlay_d3d12_render` binds that heap, then `ImGui_ImplDX12_RenderDrawData`.
- `render_d3d12.c`: `draw_overlay(rtv)` records the overlay into the renderer's command list over the back-buffer RTV
  (in `dx_present`, after the copy/resolve, only when open), then `apply_frame_state()` rebinds heaps/root sig/RT/viewport.
  Overlay is last before the present barrier. Frame dumps (`dx_read_frame`) compose the overlay on a scratch copy (`D.ovl`).
- `SMB2_TEST_RESIZE_AT=<frame>` env hook (platform_sdl2.c): 960x540 at F, 1280x720 at F+60, fullscreen toggle at F+120, F+180.
- Vendored ImGui patch (`imgui_impl_dx12.cpp`): D3DCompile and CreateDXGIFactory1 resolved with LoadLibrary/GetProcAddress, so
  the exe has no link-time d3dcompiler/dxgi import (machine may lack d3dcompiler_47 and fall back to GL; static MinGW link).

- `overlay_d3d12_invalidate()` exists but is unused: the DX12 backend has no size-dependent resources, resize only
  recreates swap-chain targets, and the renderer does not recreate the device (device removal is fatal there).

## Verified (x64, RelWithDebInfo; `tools/win_build.sh x64`)
Run from a scratch dir with `SMB2_D3D12_DEBUG=1` (debug layer), throwaway `--save-dir`:
`smb2_pc_port.exe --iso <iso> --save-dir <tmp> --audio-null --windowed --width 1280 --height 720 --renderer d3d12
 --input-script "400:START,700:START,1000:START" --dump-ranges "1560-1561,1700-1701" --exit-frame 1750 [--overlay-open-frames 1550-1650]`
- Frame 1560 with overlay shows the window over Mode Select (viewed). Same with GL.
- Closed frame 1700 of the overlay run vs a plain run: mean diff 12.6 -- same as two plain runs against each other (16.5).
  The Mode Select background (clouds/rainbow) is animated and non-deterministic run to run, so exact-equal compare is impossible
  there; visually identical.
- Resize: `SMB2_TEST_RESIZE_AT=1500` + `--overlay-open --exit-frame 1950`: 960x540, 1280x720, fullscreen 3840x2160, back; overlay
  correct after each (dumps viewed), exit 0.
- Debug layer: only one message, `id 1319 Cannot Resolve query that has never been performed` (timestamp query on first frame),
  present identically without the overlay (pre-existing in render_d3d12.c, not D2). No other errors.
- GL: `--renderer gl --overlay-open` dump at 1580 shows the overlay; log `ready (OpenGL)`.
## Gotchas
- ppmtool: build in WSL `gcc tools/ppmtool.c -lm -lz`.
- The overlay is drawn last, then `apply_frame_state()` rebinds the renderer's heaps/root signature/RT.
