# D4: Overlay tabs (partyboard look) (done, x64 only)

## What changed
- `src/overlay/overlay_ui.{h,cpp}`: shell (blue panel, #009dda border, uppercase tab bar with #00b4fa underline, left option list / right help
  pane, footer hints) and row helpers: `choice_row` (pick-one bound to `pcs_choice_*`), `volume_row`, `button_row`, `info_row`, `section`, `note`.
  A / click = next, right click = previous, Left/Right (d-pad, stick, arrows) = previous / next (the row cancels ImGui's nav move so focus stays),
  LB/RB switch tabs, Up from the first row reaches the tab bar. A **Close** tab-bar button and a **Close overlay** row at the end of every tab
  (B only backs out of nav). Help pane follows the focus (gamepad/keys) or the hover (mouse). Font: Segoe UI 20 px (fallback ImGui default),
  `FontGlobalScale = display_h / 1000` clamped 0.8..1.8.
- Tabs, one function per file: `tab_video.cpp` (display mode, resolution, aspect, restore default window size, frame rate, V-Sync, MSAA, renderer,
  Show FPS corner), `tab_audio.cpp` (volume), `tab_input.cpp` (4 port rows with controller name, button prompts, Controller sticks... [opens the
  game's stick screen, closes overlay], Open controller DB folder = exe folder), `tab_game.cpp` (language, disc image path + "Choose a different
  disc image" = forget path so the picker shows next start, Memory card screen, updates: auto check toggle / status / check now / Updates screen),
  `tab_online.cpp` (placeholder "Coming soon"), `tab_interface.cpp` (version, build, active renderer, open data folder, Quit to desktop with confirm).
  **E7**: replace the body of `ovl::tab_online()` in `tab_online.cpp` (registered in `kTabs` in `overlay_ui.cpp`); add rows with the helpers.
- `src/platform/pc_settings.c`, `include/pc_settings.h`: **choice API** `pcs_choice_count/label/current/set/enabled`, `pcs_item_restart_pending`,
  `pcs_set_volume`, `pcs_reset_window_size`, `pcs_test_set`. Every set is `pcs_item_begin_edit` + `pcs_item_step` (until the wanted index) +
  `pcs_item_confirm`, i.e. exactly what Options > Game Screen runs (apply + save). New setting `show_fps` (0 off, 1 TL, 2 TR, 3 BL, 4 BR) in settings.dat;
  **D5 draws the counter** (D4 only stores/edits the corner).
- `overlay.cpp` / `overlay.h`: calls `ovl::build`, `ovl::style_init`, close request; `overlay_test_set(kv)`. `main.c`: `--overlay-test-set key=value`
  (repeatable; applied once in `overlay_init`, i.e. after window + renderer exist, through `pcs_test_set`). Keys: display resolution vsync fps msaa
  renderer aspect volume buttons language show_fps, plus `tab=<Video|Audio|Input|Game|Online|Interface>` (selects the tab for frame dumps).
- `tools/smoke/overlay_settings.sh`: persistence test (see below). `docs/handoff/D4/*.png`: GL frame dumps of all six tabs + D3D12 Game tab.

## Gotchas
- Modal game screens (Controller sticks, Memory card, Updates screen) are requested and the overlay closes; they do not run in a netplay/E2 session (dropped).
- Memory card / updates "screens" are the game's own modal UIs, not reimplemented. Disc image change = forget path + restart (no file dialog for ISOs outside startup).
- Restart-needed rows (MSAA, renderer, language) show "(restart to apply)" in gold when they differ from this run.
- Resolution is disabled in borderless (shows desktop size), as in the game menu.
- Test setting order matters: set `resolution` before `display=borderless` (resolution is disabled in borderless).
- Frame dumps go to the process cwd (see docs/testing.md); `--overlay-open-frames 250-400` + `--dump-ranges 300-301` + `--exit-frame 302`.
- Nav-focus highlight is not visible in dumps (no nav input).
