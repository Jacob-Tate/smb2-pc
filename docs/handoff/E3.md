# E3: Input record/replay + checksums

Status: IN PROGRESS (continuation agent reviewing commit 4c62ec8; update below as work lands).

## Design
- `src/netplay/inputsync.{c,h}`: pad source LIVE / RECORD / REPLAY / NETPLAY. One exchange per `video_finish_frame` poll
  (`input_poll_gc_pads_game()`; modal screens keep the local-only `input_poll_gc_pads()`).
- Hook: `input_sdl2.c` after `game_process_sticks` + keyboard + script, before pressed/released derivation. The local sample is kept
  in `s_local_pads` and restored into `status[0]` at the next poll (status[0] holds exchanged data otherwise). Exchanged value+err
  overwrite `pad_status_groups[i].status[0]` and `lbl_80145210[i].status[0]`; `err` comes from the recording.
- Record file: header (magic SMB2REC1, build_id, disc_hash, locale, epoch, session flags, ptr size) + 4 x 9-byte SmbNetPad per poll.
  **Replay implies --det-session and takes the session config (epoch, locale, flags) from the header**; `--session-epoch` etc. are ignored
  with --replay. `--record` implies --det-session.
- Checksum: `pc_state_hash.c` (field-wise, layout independent), every 60 polls `poll N hash XXXXXXXX` in `--checksum-log`.
- `--max-frames n` stops after n polls (exit 0).
