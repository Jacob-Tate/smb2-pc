# D1: Dear ImGui overlay, SDL3 + OpenGL (done)

## What exists
- `third_party/imgui/`: Dear ImGui **1.91.9b** (MIT, `LICENSE.txt`), core + `backends/imgui_impl_{sdl3,opengl3,dx12}` (+ GL loader header).
  Source copied from partyboard's fetched checkout. The DX12 backend is NOT compiled yet (D2 adds it to `smb2_overlay`).
  Credits: README + `installer/LICENSE.txt`.
- `CMakeLists.txt`: `project(... C CXX)`, C++17, static lib `smb2_overlay` (overlay.cpp + imgui + sdl3/opengl3 backends), linked into the exe.
  `-fno-exceptions -fno-rtti`. Both toolchains already link statically (`-static`): `objdump -p` shows only system DLLs
  (no libstdc++/libgcc/winpthread/SDL).
- `include/overlay.h` / `src/overlay/overlay.cpp` (extern "C"): `overlay_init(SDL_Window*, OverlayRenderer)`, `overlay_shutdown`,
  `overlay_process_event(const SDL_Event*) -> consumed`, `overlay_new_frame`, `overlay_render`, `overlay_is_open`, `overlay_toggle`,
  `overlay_set_open`, `overlay_wants_input`, test hooks `overlay_test_open_at_start`, `overlay_test_open_frames(a,b)`.
  `io.IniFilename = NULL` (no imgui.ini). UI is a placeholder window (+ checkbox for ImGui demo).
- Hooks: `main.c` calls `overlay_init` right after renderer init (kind from the active renderer) and `overlay_shutdown` before
  `render_shutdown`; `platform_sdl2.c` `sdl2_poll_events` feeds every event to `overlay_process_event` (result ignored for now:
  the game still gets all input; F2 toggles). Flags: `--overlay-open`, `--overlay-open-frames a-b`.
- `render_opengl.c`: `glb_draw_overlay()` runs in `glb_present` before the swap, and in `glb_read_frame` (so `--dump-*` frames
  include the overlay; a flag stops the double draw). The ImGui GL backend backs up/restores program, bindings, blend, depth,
  cull, scissor, viewport; the file's client-side state mirror (`st_*`) therefore stays exact. Pixel-store UNPACK_* is restored by us.
- D3D12: `overlay_init` returns false, logs once `[overlay] not available on Direct3D 12 yet (D2)` when something asks to open.
