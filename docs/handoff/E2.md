# E2: Deterministic session mode

Status: DONE. `--det-session` (and the C API in `src/netplay/session.{c,h}`) is implemented; both arches build.
Normal play (no flag) is unchanged: every hook is one `pc_session_active()` branch.

## API (for E3/E6/E8)
- `src/netplay/session.h` (include dir `src/` added in CMake): `SessionConfig {build_id[40], disc_hash, locale, epoch u64, flags}`
  (same fields as `SmbNetSessionConfig`, no dependency on protocol.h), `pc_session_default_config`, `pc_session_begin(cfg)`
  (call once in a FRESH process, before the game starts; main.c does it from `--det-session`, `--session-epoch <n>`,
  `--session-locale <0-5>`), `pc_session_active()`, `pc_session_config()`, `pc_session_poll_count()`.
- Clock: `OSGetTime = base(epoch) + polls*675000`, `OSGetTick = (u32)time + calls_this_poll`. A "poll" = one `video_finish_frame` call
  (E1 D18). `base` = 2020-01-01 + (epoch mix mod 10 years), so different epochs give different rand/boat seeds.
- Per-poll hook: `pc_session_on_poll()` is called in `video_finish_frame` (`video_shim.c`, just before `input_poll_gc_pads()`).
  **E3: put the pad exchange (D5/D6 refactor of `input_poll_gc_pads`) and `pc_state_hash()` right there / in `pc_session_on_poll`.**
  `pc_rand_state()` accessor added in `src/detmath/pc_libc.c` for the hash.
- Debug log `[detlog] poll N rand ... mode a/b fc F script S [ball bits]` every 60 polls (`pc_session_shim.c`); temporary until E3's checksum.
- `pc_session_dbg_getenv(name)`: getenv that returns NULL in a session (use for any new sim-affecting hook).

## Limitations / notes
- The pause menus' "Quit to Desktop" row cannot be hidden from the port side (decomp `pause_menu.c`/`baseball_33.c` do
  `pc_pause_quit_row = itemCount++` unconditionally). It exists identically on all peers; choosing it exits only that peer
  (treat as disconnect in E9). The title/Mode Select quit boxes and the Options rows are gone.
- In portable mode the memory card lives next to the exe (`<exe dir>/memcard/slotA`), not in `--save-dir`; the tests used
  per-run copies of the bin dir.
- The D3D12 renderer writes `d3d12_shader_cache.bin` into the save dir (local rendering, not game state).
- Pad `err` still follows locally connected controllers (D6, E3).
- The log line `[iso] disc image saved in settings.dat` still prints in a session although nothing is written.

## Test recipe
Script (`/tmp/script1.txt` style): `420:START,640:START,900:RIGHT,960:A,1050:A,1095:A,...` every 45 frames to 1900 reaches Monkey Race
(mode 4/186) at poll ~1680 via the real menus. Run twice with `--det-session --exit-frame 1800 --input-script ...`,
different save dirs/cards/wall-clock; `grep detlog` and diff. i686 and x64 each identical across runs, `--fps 144`, `--renderer d3d12`
(and, as it happens, equal to each other).
