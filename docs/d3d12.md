# Direct3D 12 renderer: survey and plan

Status: see "Status" at the end. This file is the design record for the
D3D12 backend work.

## 1. Survey (state before this work)

### GL users in pc_port

| File | GL usage |
|---|---|
| `src/render/render_opengl.c` (~4400 lines) | everything below |
| `src/platform/platform_sdl2.c` | `SDL_WINDOW_OPENGL` window, `SDL_GL_CreateContext`, swap interval, `SDL_GL_SwapWindow`, `glReadPixels` frame dumps (`--dump-interval`) |
| `src/platform/pc_settings.c` | `SDL_GL_GetCurrentWindow` (to find the window), `SDL_GL_GetDrawableSize`, `SDL_GL_SetSwapInterval` (V-Sync item) |
| `src/game/shim/pc_settings_menu.c` | `pc_frame_capture` / `pc_frame_restore` (F1 overlay keeps the game frame) - implemented in render_opengl.c |
| `src/main/main.c` | `render_init("opengl", ...)` |

No shim uploads textures directly: every texture goes through
`GXInitTexObj` -> renderer (button_prompts.c binds decoded PNGs through the
same GX path).

### What render_opengl.c contains

1. GL function loading + a client-side GL state mirror + a uniform value cache
   (avoids driver round trips).
2. One GLSL program ("uber shader"):
   * VS: GX lighting channels (COLOR0/ALPHA0, 8 lights, spot/spec attenuation),
     texgens (TEX0..2 sources, POS, NRM with normalize + dual-tex post
     matrix), GX clip-z remap (`z' = 2z + w`, GX z/w is in [-1, 0]), eye z for
     fog, per-quad UV rect for the 2D UV clamp.
   * FS: three modes - GXFX TEV (up to 8 stages, konst, 4 regs, indirect
     texturing, alpha compare, fog), UI TEV (`tex*C0 + C1`, alpha compare),
     legacy (`vertex color * tex0`, fog).
3. The `RenderBackend` vtable (begin/end/position/..., blend/z/cull/viewport/
   scissor/clear/matrix/texture ops) - only render_opengl.c uses it.
4. GX state emulation that is not GL specific: EFB(640x448/480)->window
   mapping with an aspect box (edge-rounded rects), projection canonicalisation
   (`GXSetProjectionv`/`GXGetProjectionv`), matrix banks, immediate-mode vertex
   batching (flush on any state change because GXEnd is a no-op on GC), wide
   line expansion on the CPU, quad index buffer, 2D quad UV clamp, GC texture
   decoding (I4/I8/IA4/IA8/565/5A3/RGBA8/CMPR) and a texture cache keyed by
   identity + a content hash that frees textures with their GC memory, GXFX TEV/channel state, GXIND indirect state, texgen state,
   fog incl. the per-shape no-fog `fn_80066674`, `GXSetTexCopySrc/Dst` +
   `GXCopyTex` (read back the EFB rect, box-resample, encode into real GC
   texels at `dest`, keep a texture per dest address while the memory still
   hashes the same, optional copy-clear), the frame kickoff
   (`gx_start_new_frame` = present + EFB clear + z/alpha reset).
5. Ring-buffer vertex streaming (persistent mapped buffer + fences).
6. F1 overlay frame capture/restore (FBO blit + full-screen triangle).

### Rules the GL path relies on (must hold in D3D12 too)

* Depth clamp (no near/far clip) only for ortho draws; perspective draws clip.
* GX_CULL_FRONT/BACK map to GL with `glFrontFace(GL_CW)`; quads and expanded
  lines are never culled; `GX_CULL_ALL` culls every triangle (not points).
* Z compare off + update on still writes depth (compare = ALWAYS).
* Blend: `glBlendFuncSeparate(src, dst, ONE, ONE_MINUS_SRC_ALPHA)`, subtract =
  reverse subtract for colour and alpha.
* The frame clear ignores the scissor and paints black bars outside the aspect
  box; it obeys the current depth write mask (as glClear does).
* Copy-clear clears colour + depth of the copy rect regardless of masks.
* EFB copies return alpha 0xFF (the EFB is RGB8).
* Sampling an unbound unit returns (0,0,0,1) (GL incomplete texture).
* Default MSAA is 4x (settings.dat `msaa`, `--msaa`); reads resolve.
* Out-of-range GX enums (the game really passes some: race2 calls
  `GXSetZMode` with func 74) hit the GL switch defaults: depth func LEQUAL,
  blend src ONE / dst ZERO, unknown cull mode ignored.
* The default framebuffer is drawn y-up: edges exactly on pixel centres
  fill the visually-lower row.

## 2. Architecture

```
            game / shims (GX* calls)
                     |
   src/render/gx_core.c   backend-neutral GX emulation (everything in 4. above
                     |    + uniform-block building + EFB-copy CPU work)
                     |    GxGpu interface: src/render/gx_gpu.h
          +----------+-----------+
          |                      |
 render_opengl.c          render_d3d12.c
 (GL 3.3 core)            (D3D12 + DXGI flip model, HLSL)
```

* `gx_gpu.h` defines the small backend interface (`GxGpu`): init/shutdown,
  resize, present, vsync, viewport/scissor (window pixels, GL bottom-left
  origin - the D3D12 backend flips), blend/depth/cull, clear (optional rect),
  texture create/update/wrap/LOD/destroy/bind, `draw` (vertices + optional
  quad UV rects + two constant blocks + depth-clamp/no-cull flags),
  `read_pixels` (EFB copies), frame capture/restore (F1), `read_frame` (frame
  dumps).
* The uniform data is built once by the core into two plain C structs laid out
  exactly like the HLSL cbuffers (everything 16-byte aligned, matrices in GL
  column-major order, which is also HLSL's default `column_major` packing):
  * `GxDrawConsts` (b0): matrices, texgen masks, mode flags, alpha compare,
    UI TEV colours, fog - changes per draw.
  * `GxTevConsts` (b1): channels, lights, TEV stages, konst/regs, indirect
    state, post-texgen matrices - changes rarely; versioned.
  The GL backend uploads the same values through its existing uniform cache,
  so its output is unchanged.
* Selection: `--renderer gl|d3d12` > env `SMB2_RENDERER` > settings.dat
  `renderer=` > default `gl`. The window is created without
  `SDL_WINDOW_OPENGL` for D3D12. If D3D12 init fails the port recreates the
  window and falls back to GL.

### D3D12 backend design

* Device on the default adapter (feature level 11_0), one direct queue, DXGI
  flip-model swap chain (`FLIP_DISCARD`, 3 buffers, tearing flag when
  supported so V-Sync off really is uncapped), HWND from `SDL_GetWindowWMInfo`.
* The game renders into an offscreen colour target (RGBA8, MSAA = setting) +
  D24S8 depth. Present = resolve/copy into the back buffer. This keeps EFB
  copies, F1 capture and frame dumps independent of the swap chain.
* Root signature: b0 root CBV (draw consts), b1 root CBV (TEV consts), SRV
  table t0-t7, sampler table s0-s7.
* Descriptor heaps: a CPU-only SRV heap (one descriptor per texture) and a
  shader-visible ring that receives 8-SRV tables (copied only when the bound
  set changes); a shader-visible sampler heap with a cache of 8-sampler tables
  keyed by the per-stage sampler state.
* Upload ring (persistently mapped UPLOAD heap, fenced per frame) for
  vertices, quad rects and constant blocks; constant blocks are deduplicated by
  memcmp against the last upload. Texture uploads go through the same ring
  (or a dedicated buffer for big ones) with `CopyTextureRegion`.
* PSO cache: the whole pipeline key (blend enable/src/dst/op, depth func/write,
  cull, depth clip, topology class) fits in 16 bits, so the cache is a flat
  65536-entry array: lookup is one load.
* Quads and triangle fans use static index buffers (D3D12 has no fans);
  lines are already expanded to triangles by the core.
* Shaders: HLSL port of the GLSL, compiled at startup with `D3DCompile` from
  `d3dcompiler_47.dll` (loaded dynamically; ships with Windows 10+), SM 5.1.
  Reason for runtime compilation: the WSL/mingw build has no fxc/dxc, and the
  shader is one uber shader compiled once (0.5-0.9 s); the bytecode is cached
  in `<save dir>/d3d12_shader_cache.bin` keyed by a hash of the source, so
  later starts skip the compile.
  HLSL notes: every function has a single exit (FXC miscompiled the TEV path
  with early returns - X4000 warnings, black output), and the TEV loop uses
  `SampleGrad` with derivatives of the texcoords taken before the loop
  (implicit-derivative sampling is not allowed in a dynamic loop).
* Rasterization: the VS nudges y by 1/256 pixel so edges on pixel centres
  fill the same row as GL (y-up); MSAA uses D3D's standard sample pattern.
* EFB copies (both backends, `gx_core.c` GXCopyTex): colour copies in the
  formats with a GPU conversion (I4/I8/IA4/IA8/565/5A3/RGBA8 and the R/RA/RG/GB
  copy formats) never stall: `copy_tex` resolves the target, box-resamples
  the rect on the GPU (the exact integer mean of the CPU loop) into a dw x dh
  UINT target and, in the same pass, writes the texels the copy format reads
  back as (natural sample format) straight into the game's texture; the raw
  result goes to a readback buffer (D3D12: per ticket, completes with the
  frame fence; GL: PBO + fence) and gx_core encodes it into GC memory at
  `dest` a frame or so later (polled per frame, forced before anything needs
  the bytes, dropped if the game rewrote that memory meanwhile). Other
  formats use `read_pixels_box` (same GPU resample, synchronous readback of
  dw x dh); depth copies the full-size `read_pixels` + CPU path.
  `SMB2_COPY_CPU_RESAMPLE=1` forces the old CPU path, `=2` verifies the GPU
  paths against it (`[copyverify]`), `=3` disables the async path. Before
  this, the stage select's per-frame full-screen copy cost 10-16 ms at
  1440p/MSAA 8x (full-size readback through a GPU drain + CPU resample).
* Frame dumps: same readback path at present time.
* Debug: `SMB2_D3D12_DEBUG=1` enables the debug layer and prints the info
  queue messages to stderr. Device removal: logged with the removed reason,
  then a clean exit.

## 4. Status (end of this work)

### Selecting the renderer

* `--renderer gl|d3d12` (also `dx12`), else env `SMB2_RENDERER`, else
  `renderer=` in settings.dat, else `gl`.
* In game: F1 overlay or Options > Game Screen > "Renderer"
  (OpenGL / Direct3D 12, "(restart)" shown until the next launch).
* If D3D12 cannot start (no d3d12.dll / dxgi / d3dcompiler_47, no FL 11_0
  device, ...) the window is recreated for GL and the game runs on GL.
* Debug: `SMB2_D3D12_DEBUG=1` debug layer (+ info queue to stderr), `=2` adds
  GPU-based validation. Test/diagnostic switches: `SMB2_D3D12_FORCEFAIL`
  (exercise the GL fallback), `SMB2_D3D12_DEBUGVIS=n` (shader debug views),
  `SMB2_D3D12_NOCULL`, `SMB2_D3D12_NODEPTH`, `SMB2_D3D12_FLIPFACE`,
  `SMB2_D3D12_TRACECOPY`.

### Parity results

See the final report / commit log for the per-scene table; method: same
input script, `--dump-interval`, GL vs D3D12 frame dumps compared with
`tools/ppmtool diff` (max / mean / % pixels differing, % differing by > 24)
and side-by-side sheets (`ppmtool sheet`: GL | D3D12 | heat map).

* Deterministic frames, MSAA off (intro 100-500, menus attract): identical or
  max difference 3/255.
* With the default 4x MSAA, geometry edges differ slightly (GL driver vs D3D
  standard sample positions).
* Gameplay frames: the game is not deterministic (wind, COM characters,
  baseball roulette, animation phase), so GL-vs-GL runs differ as much as
  GL-vs-D3D12; visual sheets show no rendering differences.

### Known differences / limitations

* Mipmaps are generated on the CPU (2x2 box) instead of glGenerateMipmap:
  low-amplitude (a few levels) differences on minified textures.
* MSAA edge coverage differs from GL (sample pattern).
* Depth EFB copies (`GXCopyTex` with a Z format) return 0 under MSAA
  (multisampled depth can't be resolved); the game uses no Z copy formats.
* Textures are committed resources (64 KB alignment each).  Both backends
  free them when the core retires them ("Texture lifetime" in gx_core.c:
  their GC texel memory was freed / handed to a new heap / rewritten, or
  unused while over SMB2_TEX_BUDGET); D3D12 releases the resource after the
  GPU fence and reuses the CPU SRV slot.
* Shared with GL (kept for parity, not fixed here): the batch still pending
  at present time is drawn into the next frame and cleared (GXEnd is a no-op,
  nothing flushes before the swap).  (GL's `glb_tex_create` used to leave
  the new texture bound on the active unit; it now restores the binding.)
* `[d3d12] adapter ... MB` prints a truncated size in the 32-bit build.
